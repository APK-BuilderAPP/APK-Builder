APK-Builder：

About APP:
This app adopts an extremely lightweight design, occupying only 23MB. It is perfectly suitable for your device. Best supports Android 8.1, minimum supports Android 4.4. If Google pops up a "built for an older version of Android" warning, just ignore it, it is designed to be compatible with older devices. It uses Smali 2.5.2 and Android 12 jar packages to make compilation simpler. Tutorials will be added later to teach beginners how to create their first app from scratch. Because currently only version 1.1 is adapted for English, you need to wait three months for English adaptation. While adapting English, more features will be added, and a Changelog will be introduced in version 1.1 so people who haven't used the software will know what has been updated.

Usage:
Click "New Project", enter the package name and app name. Note: The package name can only contain letters and numbers, no special symbols are allowed. If an error occurs, don't blame me, it's because you didn't enter the correct format. The app name can be anything. After generation is complete, you can modify the smali and AndroidManifest.xml. If generation is complete, the log output path is "/storage/emulated/0/AppBuilderProjects/your_project/build". You can click to install directly, and there will be no installation failure (unless you change the signature). After installation, if you see your own interface, it is successful. Very suitable for people without a computer.

Features and Inspiration:
After compiling the files, if there is a ❌, it means there is a problem. Please read the errors in the log carefully and modify them until there is a ✔️, then you can install it. The purpose of me making this tool is: on a dark and windy day, my computer suddenly exploded on the spot, blowing out a mushroom cloud with a radius of ten millimeters, almost blowing me to death. To prevent this from happening, I made a mobile APK tool. It can prevent computer explosions and also compile files on mobile. This masterpiece was made using my neighbor's computer.
